# CompTIA Security+ 考試準備

本專案提供英文原創練習題與繁體中文介面，供 Security+ 概念學習與錯題複習。畫面樣式參考 ipas-quiz，內容依 Security+ 官方考綱建立。

## 使用方式

需 Node.js 18 或更新版本，無第三方套件，無須 npm install。

```powershell
cd D:\Document\CompTIA
npm start
```

開啟 <http://127.0.0.1:4173>。可選版本、題組、領域、題數與隨機排序。每題預設英文，按「翻譯成中文」同步切換題幹、選項與解析；按「Back to English」返回英文，已選答案與作答結果會保留。下一題回到英文。

作答後顯示逐選項解析與來源，完成後可翻譯錯題解析、只重練錯題。抽題限於選定題組，實際題數不超過該題組或領域的題數。資料及作答狀態留在本機，重新整理頁面後清除本次紀錄。

## 題庫

| 版本 | 題組與總題數 | Objective 覆蓋 | 每組 Domain 1–5 題數 | 考綱文件版本 |
| --- | --- | --- | --- | --- |
| [SY0-701](exam/json/security-plus-sy0-701-01.json) | 11 組，390 題：01 為 90 題，02–11 各 30 題 | 全題庫 28 / 28；01 亦完整覆蓋 | 01：11 / 20 / 16 / 25 / 18；02–11：4 / 7 / 5 / 8 / 6 | 6.0 |
| [SY0-801](exam/json/security-plus-sy0-801-01.json) | 1 組，90 題 | 27 / 27 | 14 / 22 / 17 / 24 / 13 | 2.0 |

共 480 題，每題標註 exam code、domain、objective、答案、四項解析與來源。兩版與各題組分開篩選；SY0-801 包含 AI 風險與 AI-assisted workflows。領域分布按官方比重取近似整數，30 題組用於分段練習。新增組各有獨立題目，並非把同一批題目重新排序。

題目使用有明確限制的英文情境，練習選擇最佳措施、判斷處理順序、辨識攻擊與資料判讀；部分題目包含 firewall/ACL、log、RTO/RPO 或 ALE 計算。這些是依考綱設計的練習方式，不能保證與正式試卷的難度或措辭相同。

本題庫是原創單選、複選與情境練習，未實作互動 PBQ，也不收錄考場回憶題或 brain dumps。每題等權重，複選需完全答對；答對率不換算正式考試的 100–900 量尺分數。

考試時程查核日期：2026-10-06；本次題庫更新與 SY0-701 考綱複核：2026-10-07（Asia/Taipei）。依時程查核結果，SY0-701 可報考，SY0-801 預計於 2026-11-17 前後推出。應試前請再次確認官方時程。詳見 [資料研究與來源索引](docs/security-plus-research.md) 與 [題庫格式與維護](docs/question-bank.md)。

## 驗證

```powershell
npm test
```
